# Skill: Information Architecture

## Purpose
Provide the UX Agent with the ability to design, evaluate, and refine the **information architecture (IA)** of uFawkes.dev.  
This includes navigation models, content hierarchy, labeling systems, and structural clarity.

## Used By
- UX Agent
- Planning Agent
- Review Agent (for IA alignment)

## Capabilities
- Analyze existing site structure and identify gaps or redundancies.
- Propose hierarchical IA models (global nav, local nav, footer, docs sidebar).
- Create labeling systems that match user mental models.
- Produce IA diagrams, structured lists, and navigation maps.
- Evaluate IA against user journeys and content strategy.

## Outputs
- IA diagrams (text-based)
- Navigation models
- Page hierarchy lists
- Labeling recommendations
- Structural change proposals

## Constraints
- Does not modify code.
- Does not define visual design.
- Must align with UX principles and content strategy.
