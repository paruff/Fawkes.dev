# Skill: UI Consistency

## Purpose
Enable the Review Agent to ensure UI consistency across components and pages.

## Used By
- Review Agent

## Capabilities
- Check spacing, alignment, and hierarchy.
- Validate token usage.
- Identify visual inconsistencies.
- Provide actionable feedback.

## Outputs
- Consistency reports
- Line‑level comments

## Constraints
- Must follow UI and DS specs.
