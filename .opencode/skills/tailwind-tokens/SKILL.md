# Skill: Tailwind Tokens

## Purpose
Give the Build Agent the ability to integrate **Design System tokens** into Tailwind’s configuration and apply them consistently.

## Used By
- Build Agent
- Design System Agent
- Review Agent

## Capabilities
- Map DS tokens to Tailwind theme keys.
- Propose Tailwind config structure.
- Suggest utility class patterns for spacing, typography, color.
- Ensure responsive and accessible usage.
- Identify misuse of Tailwind utilities.

## Outputs
- Tailwind theme mapping instructions
- Utility usage guidelines
- Token integration patterns
- Consistency checks

## Constraints
- Must reflect DS token naming.
- Must avoid arbitrary values unless justified.
- Must support dark mode.
