# Skill: Interaction & Motion

## Purpose
Enable the UI Agent to define micro‑interactions and motion patterns.

## Used By
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Define hover, focus, and active transitions.
- Propose motion curves and durations.
- Provide motion‑reduction rules.
- Ensure interactions support clarity and usability.

## Outputs
- Interaction rules
- Motion guidelines
- Transition tables

## Constraints
- Must support accessibility (reduced motion).
