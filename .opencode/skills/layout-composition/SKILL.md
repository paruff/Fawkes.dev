# Skill: Layout Composition

## Purpose
Enable the UI Agent to design clear, balanced, and responsive **layout compositions**.

## Used By
- UI Agent
- Review Agent

## Capabilities
- Define grid systems and alignment rules.
- Establish spacing and rhythm.
- Propose responsive breakpoints and behavior.
- Evaluate layout clarity and balance.

## Outputs
- Layout rules
- Grid definitions
- Responsive behavior guidelines
- Composition critiques

## Constraints
- Must use DS tokens.
- Must align with UX wireframes.
