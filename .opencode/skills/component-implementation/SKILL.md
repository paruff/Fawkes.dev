# Skill: Component Implementation

## Purpose
Enable the Build Agent to implement reusable components in Astro.

## Used By
- Build Agent
- Review Agent

## Capabilities
- Implement DS component anatomy.
- Apply UI styling rules.
- Ensure accessibility and responsiveness.
- Provide reusable component APIs.

## Outputs
- Astro components
- Props/slots definitions
- Implementation notes

## Constraints
- Must follow DS tokens and UI specs.
