# Skill: Experience Principles

## Purpose
Give the UX Agent the ability to define **experience principles** that guide all design and implementation decisions.

## Used By
- UX Agent
- UI Agent
- Design System Agent
- Review Agent

## Capabilities
- Create 5–8 principles that define the “feel” of uFawkes.
- Provide rationale and examples.
- Evaluate decisions against principles.
- Ensure consistency across the ecosystem.

## Outputs
- Experience principles
- Examples and anti‑examples
- Evaluation criteria

## Constraints
- Must be actionable, not abstract.
- Must align with Fawkes brand values.
