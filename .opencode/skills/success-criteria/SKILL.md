# Skill: Success Criteria

## Purpose
Enable the Planning Agent to define measurable success criteria for phases and tasks.

## Used By
- Planning Agent
- Review Agent

## Capabilities
- Define measurable outcomes.
- Propose acceptance criteria.
- Align criteria with UX/UI/DS/Build goals.

## Outputs
- Success criteria lists
- Acceptance criteria

## Constraints
- Must be objective and testable.
