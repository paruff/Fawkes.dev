# Skill: UX Alignment

## Purpose
Enable the Review Agent to validate that implementations match UX wireframes and flows.

## Used By
- Review Agent

## Capabilities
- Compare implementation to UX wireframes.
- Validate content hierarchy.
- Check flow alignment.
- Identify UX deviations.

## Outputs
- UX alignment reports
- Fix recommendations

## Constraints
- Must follow UX wireframes and IA.
