# Skill: Design System Documentation

## Purpose
Enable the Design System Agent to produce clear, maintainable documentation for the Fawkes Design System (FDS).

## Used By
- Design System Agent
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Document tokens, components, patterns, and rules.
- Provide examples and usage guidelines.
- Define anti‑patterns.
- Produce GitHub‑friendly markdown documentation.

## Outputs
- DS documentation pages
- Component usage guidelines
- Pattern documentation
- Token reference tables

## Constraints
- Must be implementation‑ready.
- Must align with UX and UI specs.
