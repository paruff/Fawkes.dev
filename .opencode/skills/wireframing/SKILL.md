# Skill: Wireframing

## Purpose
Give the UX Agent the ability to produce **low‑fidelity wireframes** for pages, layouts, and flows.

## Used By
- UX Agent
- UI Agent
- Review Agent

## Capabilities
- Create structural layouts for pages (homepage, docs, product pages).
- Define content hierarchy and placement.
- Propose layout patterns (hero, grid, sidebar, footer).
- Annotate wireframes with rationale and behavior notes.

## Outputs
- Wireframes (text-based)
- Layout annotations
- Structural recommendations

## Constraints
- Must not include visual styling.
- Must align with IA and content strategy.
