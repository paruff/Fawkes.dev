# Skill: User Journeys

## Purpose
Enable the UX Agent to map, analyze, and optimize **user journeys** across the uFawkes ecosystem.

## Used By
- UX Agent
- Planning Agent
- Review Agent

## Capabilities
- Identify key personas (Builder, Operator, Contributor).
- Map end‑to‑end flows for each persona.
- Identify friction points and opportunities.
- Align journeys with IA and content strategy.
- Produce journey diagrams and step‑by‑step flows.

## Outputs
- Journey maps
- Persona definitions
- Flow diagrams (text-based)
- Friction analysis
- Recommendations for UX improvements

## Constraints
- Must align with IA and experience principles.
- Does not define UI or visual design.
