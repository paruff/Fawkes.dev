# Skill: Responsive Design

## Purpose
Enable the UI Agent to define responsive behavior across breakpoints.

## Used By
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Define breakpoints and responsive rules.
- Propose mobile‑first layout adjustments.
- Ensure readability and usability across devices.
- Evaluate responsive behavior in existing layouts.

## Outputs
- Breakpoint definitions
- Responsive rules
- Mobile/desktop layout guidelines

## Constraints
- Must align with DS tokens and layout patterns.
