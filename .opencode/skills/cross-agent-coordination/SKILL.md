# Skill: Cross-Agent Coordination

## Purpose
Enable the Planning Agent to coordinate work across UX, DS, UI, Build, Review, and Infra agents.

## Used By
- Planning Agent

## Capabilities
- Define handoff rules.
- Identify cross‑agent dependencies.
- Ensure sequencing and alignment.
- Propose `/oc` command flows.

## Outputs
- Coordination plans
- Handoff guidelines

## Constraints
- Must reflect actual agent responsibilities.
