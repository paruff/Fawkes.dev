# Skill: Layout Implementation

## Purpose
Enable the Build Agent to implement layouts in Astro + Tailwind.

## Used By
- Build Agent
- Review Agent

## Capabilities
- Implement layout templates (homepage, docs, product pages).
- Apply DS tokens and UI specs.
- Ensure responsive behavior.
- Maintain semantic HTML.

## Outputs
- Layout templates
- Implementation notes
- Responsive markup

## Constraints
- Must follow UX → DS → UI specs.
