# Skill: Roadmapping

## Purpose
Enable the Planning Agent to create phased, high‑leverage roadmaps.

## Used By
- Planning Agent

## Capabilities
- Define phases, milestones, and timelines.
- Sequence work across agents.
- Identify leverage points.

## Outputs
- Roadmaps
- Milestone definitions

## Constraints
- Must align with UX → DS → UI → Build → Review workflow.
