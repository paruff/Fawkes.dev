# Skill: Content Strategy

## Purpose
Enable the UX Agent to define **what content belongs where**, and how it should be structured to support user goals.

## Used By
- UX Agent
- Planning Agent
- Review Agent

## Capabilities
- Define narrative structure (Why → What → How → Proof → Next Steps).
- Recommend content hierarchy for pages.
- Identify content gaps and redundancies.
- Propose tone, clarity, and messaging guidelines.

## Outputs
- Content outlines
- Narrative structures
- Messaging guidelines
- Content audits

## Constraints
- Must align with IA and experience principles.
- Does not write final marketing copy.
