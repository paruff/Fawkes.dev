# Skill: Visual Hierarchy

## Purpose
Give the UI Agent the ability to create clear, intentional **visual hierarchy** across pages and components.

## Used By
- UI Agent
- Review Agent

## Capabilities
- Define heading scales and typographic rhythm.
- Establish spacing rules and vertical rhythm.
- Prioritize content using contrast, weight, and scale.
- Recommend emphasis patterns (color, weight, spacing).
- Evaluate hierarchy clarity in existing designs.

## Outputs
- Hierarchy rules
- Heading scale tables
- Spacing rhythm guidelines
- Emphasis patterns
- Hierarchy critiques

## Constraints
- Must use Design System tokens.
- Must align with UX structure.
- Must support accessibility (contrast, readability).
