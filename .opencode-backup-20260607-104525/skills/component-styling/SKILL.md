# Skill: Component Styling

## Purpose
Enable the UI Agent to define the **visual styling** of components using DS tokens.

## Used By
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Apply tokens to component anatomy.
- Define color, spacing, typography, and motion.
- Provide responsive styling rules.
- Define hover, focus, and active states.

## Outputs
- High‑fidelity component specs
- Styling rules
- State definitions
- Responsive styling guidelines

## Constraints
- Must use DS tokens.
- Must align with UX structure.
