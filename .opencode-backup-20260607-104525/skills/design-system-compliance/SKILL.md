# Skill: Design System Compliance

## Purpose
Enable the Review Agent to validate whether implemented components and layouts **conform to the Fawkes Design System (FDS)**.

## Used By
- Review Agent
- Design System Agent

## Capabilities
- Check token usage (color, spacing, typography).
- Validate component anatomy and variants.
- Identify deviations from DS patterns.
- Evaluate accessibility compliance.
- Provide actionable feedback for Build/UI agents.

## Outputs
- Compliance reports
- Line‑level review comments
- Token usage audits
- Component consistency checks

## Constraints
- Must reference DS tokens and component specs.
- Must not propose new design patterns (DS Agent handles that).
- Must remain objective and implementation‑focused.
