# Skill: Astro Components

## Purpose
Enable the Build Agent to implement clean, modular, reusable **Astro components** that follow UX, UI, and DS specifications.

## Used By
- Build Agent
- Review Agent

## Capabilities
- Propose component structure (props, slots, composition).
- Recommend file organization patterns.
- Suggest reusable component patterns (UI, layout, patterns).
- Ensure semantic HTML and accessibility.
- Provide implementation guidance for DS tokens.

## Outputs
- Component structure proposals
- Implementation notes
- Accessibility recommendations
- Composition patterns

## Constraints
- Does not write full production code.
- Must follow DS tokens and UI specs.
- Must maintain semantic HTML.
