# Skill: Component Anatomy

## Purpose
Enable the Design System Agent to define the **structure, states, and variants** of reusable components.

## Used By
- Design System Agent
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Define component anatomy (slots, sections, hierarchy).
- Define states (default, hover, focus, active, disabled).
- Define variants (primary, secondary, subtle, destructive).
- Provide accessibility requirements.

## Outputs
- Component anatomy diagrams (text-based)
- State tables
- Variant definitions
- Accessibility notes

## Constraints
- Must use DS tokens.
- Must align with UX wireframes and UI direction.
