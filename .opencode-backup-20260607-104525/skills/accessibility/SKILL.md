# Skill: Accessibility

## Purpose
Enable the Design System Agent to define accessibility rules for components, tokens, and patterns.

## Used By
- Design System Agent
- UI Agent
- Build Agent
- Review Agent

## Capabilities
- Define WCAG AA contrast requirements.
- Define focus states and keyboard navigation.
- Recommend ARIA usage.
- Provide motion‑reduction guidelines.

## Outputs
- Accessibility rules
- Contrast tables
- Focus state guidelines
- ARIA recommendations

## Constraints
- Must follow WCAG AA or better.
