# Skill: Pattern Library

## Purpose
Give the Design System Agent the ability to define **layout and interaction patterns** for uFawkes.dev.

## Used By
- Design System Agent
- UX Agent
- UI Agent
- Build Agent

## Capabilities
- Define layout patterns (hero, grid, docs layout, product pages).
- Define interaction patterns (navigation, CTAs, cards).
- Provide usage rules and anti‑patterns.
- Ensure consistency across pages.

## Outputs
- Pattern definitions
- Layout rules
- Interaction guidelines
- Pattern usage documentation

## Constraints
- Must use DS tokens and component anatomy.
- Must align with UX structure.
